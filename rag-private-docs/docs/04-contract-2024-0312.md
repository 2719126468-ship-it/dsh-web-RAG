# 软件开发外包合同

**合同编号：** DEV-2024-0312
**签订日期：** 2024 年 3 月 12 日
**甲方：** 蓝海科技有限公司
**乙方：** 码神信息技术有限公司

## 第一条 项目内容

乙方为甲方开发"智能客服系统 v2.0"，包括但不限于：
- 后端 API 服务（Python + FastAPI）
- 前端管理后台（React + TypeScript）
- 第三方对接（微信客服、钉钉机器人）
- 数据看板（用户会话量、响应时长、满意度）

## 第二条 项目周期

- **开发周期**：自合同签订之日起 90 个自然日
- **里程碑**：
  - M1（第 30 天）：完成 API 设计文档 + 数据库设计
  - M2（第 60 天）：完成核心功能开发，进入联调
  - M3（第 90 天）：完成 UAT 验收，部署上线
- **延期罚则**：每延期 1 天，扣合同总额 0.5%，最高不超过 10%

## 第三条 合同金额

- **总金额**：人民币 480,000 元（含税）
- **付款方式**：
  - 签约后 7 个工作日内：30%（144,000 元）
  - M1 验收通过后：30%（144,000 元）
  - M2 验收通过后：30%（144,000 元）
  - 终验合格后 30 日内：10%（48,000 元）
- **发票**：乙方需在每次收款前 5 个工作日内开具增值税专用发票

## 第四条 知识产权

- 项目源代码所有权归甲方所有
- 乙方不得将项目代码用于其他客户
- 乙方可复用通用工具类库（需在交付文档中说明）

## 第五条 保密条款

双方对在本合同履行过程中知悉的对方商业秘密负有保密义务，保密期限为本合同终止后 **3 年**。

## 第六条 违约责任

- 任一方违约，应赔偿对方因此遭受的直接经济损失
- 乙方代码存在严重缺陷且拒不修复的，甲方有权解除合同

## 争议解决

本合同适用中华人民共和国法律，争议由北京仲裁委员会仲裁解决。
