# 项目 22：RAG 私人文档问答

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大语言模型（LLM）在回答问题时参考外部知识库的技术。

## 核心流程

1. **索引阶段**：把文档切块 → 转为向量 → 存入向量数据库
2. **检索阶段**：用户提问 → 也转为向量 → 在数据库中找最相似的 Top-K 片段
3. **生成阶段**：把检索到的片段作为上下文，连同问题一起交给 LLM，生成带引用的答案

## 优势

- 答案基于真实文档，不会胡编
- 可以引用原文，方便核查
- 知识库更新无需重新训练模型
- 私有数据不出本地，安全性高

## 与传统搜索的区别

传统搜索靠关键词匹配，RAG 靠语义相似度。即使你问的问题里没有出现文档中的关键词，只要意思相近，就能找到相关内容。
