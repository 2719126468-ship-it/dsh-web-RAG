# 线上故障复盘：2025-02-08 订单服务

**故障时间：** 2025 年 2 月 8 日 14:32 - 16:18，共 106 分钟
**影响范围：** 订单服务不可用，用户无法下单
**严重级别：** P0

## 时间线

- 14:32 监控告警：订单服务错误率突升
- 14:35 值班工程师介入
- 14:50 定位到数据库连接异常
- 15:20 尝试重启服务，无效
- 15:45 找到根因：连接池配置错误
- 16:10 修复配置并灰度
- 16:18 服务恢复

## 根因

上线新版本时，数据库连接池最大连接数被错误地配置为 5（正确值应为 200），
导致高并发下所有请求排队超时。

## 改进措施

1. 连接池配置加入 CI 校验，禁止低于 100
2. 关键配置变更需二次确认
3. 增加数据库连接数实时监控
4. 完善故障响应 SOP

## 责任人

本次事故由发布流程缺陷导致，具体责任认定由 HR 与工程 VP 另行评估。
