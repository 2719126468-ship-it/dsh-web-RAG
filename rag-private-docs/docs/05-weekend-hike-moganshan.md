# 周末徒步笔记 - 莫干山

**日期：** 2024 年 10 月 19 日（周六）
**天气：** 多云转晴，18°C，舒适
**路线：** 莫干山风景区 - 剑池 - 芦花荡 - 怪石角

## 行程

早上 7 点从杭州出发，自驾 1.5 小时到莫干山景区门口。

### 装备清单

- 登山鞋（重要，路上石阶多）
- 速干衣 + 薄外套（早晚温差大）
- 2L 水 + 3 根能量棒
- 头灯（剑池那段很暗）
- 充电宝

### 实际用时

- 9:00 到达景区，买了门票（80 元）
- 9:30 开始上山
- 11:00 到达剑池（最有名的景点，瀑布很壮观）
- 12:30 在芦花荡吃农家午饭（红烧肉 + 笋干 + 米饭，60 元/人）
- 14:00 怪石角，需要爬一段野路
- 16:30 下山，开车回杭州

## 感受

莫干山的竹海真的名不虚传，空气超好。剑池那段台阶很陡，下过雨后有点滑。怪石角那段野路人少，但风景好。

## 注意事项

1. **导航**：高德地图搜"莫干山风景区-东门"
2. **停车**：东门停车场 20 元/天
3. **吃饭**：山上有几家农家乐，午市人多，建议早去
4. **天气**：雨天路滑，建议晴天或阴天去
